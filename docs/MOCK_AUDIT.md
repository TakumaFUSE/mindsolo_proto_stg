## 3.5 feed

| # | 種別 | 内容 |
|---|------|------|
| F-01 | 🔴 | **検索UIがインライン常時表示**（`<div class="search-row">`）。SPEC ではヘッダーに検索ボタンを置き、押下でモーダルが起動する方式。`search-row` と絞り込みチップを削除し、ヘッダーに検索ボタンを追加する必要がある |
| F-02 | 🔴 | **絞り込みチップ**（感情で絞る / 日付順 / 未読提案）が常時インライン表示。SPEC のフィルタは「type（entry / thread）」と「日付順」のみで、検索モーダル内に配置する。`感情で絞る` と `未読提案` チップは SPEC に存在しない概念 |
| F-03 | 🔴 | **振り返り提案カードに既読/未読の視覚的区別がない**。SPEC §3.5「未読: ハイライト、既読: グレーアウト」。全カードが同スタイルのまま |
| F-04 | 🟡 | 振り返り提案カードが押下不可（`data-go` なし、クリックイベントなし）。少なくともクリック時に既読扱いになるインタラクションが必要 |
| F-05 | 🟡 | `streak-pill`（「7 day streak」）が表示されているが SPEC 未定義。削除する |
| F-06 | 🟡 | ウェルカムエリアのサブテキスト「今日の記録候補: 3件 / メンター提案: 2件」が SPEC 未定義。削除する |
